# S02 content strategy (series name: "India Built It Anyway"; folder keeps the stable id `S02_DENIED-...`)

Principle: watch time decides reach, so every film is a promise-and-answer. Hook (a question in the first 5 to 20 s) -> build-up (open loops that keep the question alive) -> payoff (the answer, in the last 30 s). The creator advice you pasted is used as a set of hypotheses to test, not as facts: only "watch time/retention matters" and the three kinds of value are well supported; the "three videos in a row changes the next video's initial audience" rule is folklore with no source I can verify, so it is tracked, not relied on.

## 2. Retention checkpoints (editing targets)
0:00 to 0:05 striking image + unanswered question. 0:20 reason to care. Every 45 to 60 s a new curiosity gap (a "?" box, a hidden part, a number about to be revealed). Mid-film (about 2:30) the fictional scenario or the honest number as a pattern break. Last 30 s the payoff and a quiet final line. No logo bumper; title card at most 2.5 s.

## 4. Release order and cadence
E01 first (strongest evidence), then E03 (NavIC is in the news: NVS-03 launched 30 Oct 2026, so release while the story is fresh and re-check the ledger on the day), then E02, E06, E05, E04. Weekly cadence. Keep Shorts at or under 40% of uploads (see CHANNEL_PLAN).

## 5. Shorts and Reels: five versions each (specification only; not part of the first build run)
For each film cut three Shorts from the script's best passages (hook short, engineering explainer, honest frontier). For each Short make **five versions** that differ in ONE or TWO components only: (1) opening line, (2) first visual, (3) caption style, (4) length (20 / 30 / 45 s), (5) ending line. Post all five to Reels and Shorts on different days, track hook-hold (viewed vs swiped), average view duration and subs gained in the tracker (CHANNEL_PLAN), and keep the best. Vertical versions need their own layout (`layout: "v"`), not a crop of the 16:9 master.

## 6. Reuse and iteration
If a film performs, change one or two components (title, thumbnail, first 15 s) and re-test; prefer editing the existing video's title/thumbnail (YouTube Studio's title/thumbnail test feature, check it is available on your channel) over uploading a duplicate, which can be flagged as repetitive. Borrow the STRUCTURE of proven formats (denied -> decision -> build -> still missing), not their blame framing.
