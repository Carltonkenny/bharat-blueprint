### 3. THE SCRIPT
Spoken narration only, 500 to 560 words, plain words, short sentences, written for the ear. Structure (use these labels as section headers, spoken text under each):

 DECISION: who decided what, and when (ledger facts).
 IDEA 1 / IDEA 2 / IDEA 3: three ideas that explain how the machine works.  FICTIONAL SCENARIO: a 3 to 5 line what-if, introduced by the spoken words "Here is a fictional scenario." It must teach something about the technology (for example what happens if a part is missing), never describe a real event or a real person, and never involve a named country.

Use the same recommended option in all five episodes.
