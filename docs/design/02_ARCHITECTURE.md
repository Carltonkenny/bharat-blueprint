# 02 Architecture: target structure

## Principles
1. **One source of truth per fact.** The script lives once (`script.json`); timing, narration text, captions-to-come, clip ids and scene names are derived from it.
2. **Generated vs authored is explicit.** Generated files start with `// GENERATED by bb gen from <inputs>. Do not edit.` and are reproducible byte-for-byte (`bb gen` twice gives identical files). Authored files are the only ones a human or agent edits.
3. **The film stays a pure function of time.** No change to how frames are drawn; this refactor moves data out of copied code.
4. **Migration is proven, not trusted.** Existing episodes are never edited in place. A migrated copy must reproduce the old film's frames pixel-for-pixel (T2).
5. **Everything costly or public is gated and dry-run by default.**

Existing S01 episodes stay where they are, unchanged, until their migration ticket is approved. Ep1 is never migrated.

## How a generated episode runs
`index.html` (generated) loads, in order: kit engine files, the generated `episode-data.js` (`window.EPISODE = {...}`, built by `bb build` from `episode.json`+`script.json`+`beats.json`, which stay the authored source of truth; JSON cannot be loaded from a `file://` page, so no tool may load the JSON files directly), `narration/measured.js`, kit `timing-core.js` (builds `window.TIMING` from the data exactly as today's `timing.js` does), `panels.js`, kit `film-core.js` (builds `BEATS`, HUD, camera exactly as today's `film.js` does). Fonts are loaded from the kit.
The HUD label (`EPnn`) and scene names come from `episode.json`; nothing episode-specific is typed in kit code.

## Determinism and portability
- Chrome: resolved via `CHROME_PATH`, else `puppeteer.executablePath()`, else a documented per-user fallback in `_shared/cli/config.json` (not committed with user paths in code).
- All paths relative to the workspace root; the CLI finds the root by walking up to `package.json` with `"bbWorkspace": true`.
- Encoding: all files UTF-8 without BOM, LF. A test fails on anything else.
- Randomness: fixed seeds (as in today's sound synthesis).

## Out of scope for the first milestones
Changing the look, re-recording voices, re-rendering existing episodes, auto-writing scripts, auto-uploading.
